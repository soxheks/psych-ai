# 页面动效设计说明

## 设计目标

页面转场服务于信息层级和情绪连续性：用户从首页进入 AI 对话或心灵随笔时，应感到自己正在进入同一产品中的另一个“陪伴空间”，而不是突然切换到无关页面。

## 参考与原创转换

本次研究参考了《崩坏：星穹铁道》活动 UI 留档及游戏 UI 动效分析，但没有复制游戏图形、角色、标志、音效或源文件。

- GameRes《动效设计的功能性-视觉引导》：采用“主信息先出现、从属信息跟随”的层级节奏。
- UI 状态分析文章：参考悬停时轮廓提亮、按下时明度和尺度变化等明确状态反馈。
- 《狐斋志异》活动 UI 留档：观察活动页面中斜向构图、细线轨迹和几何层叠的视觉语言。

项目将这些规律转换为原创的“心研同伴”动效：深青遮罩代表进入安静空间，薄荷色斜切层连接现有视觉体系，暖金细线作为短暂的方向引导，中央菱形标记与页面标题承担主信息。

## 动效结构

1. 用户按下入口时，按钮先产生局部涟漪和轻微压缩，确认操作已被接收。
2. 深青背景从右侧快速覆盖，薄荷斜切层与暖金线从反方向穿过，形成明确运动方向。
3. 页面名称和项目标记随后出现，帮助用户理解目标页面。
4. 新页面加载后遮罩反向离场，内容重新成为视觉主体。

## 交互反馈

- 主要链接悬停时提亮边框、轻微抬升或横移。
- 图标会根据鼠标位置进行不超过数像素的轻微跟随。
- 按下时显示局部涟漪并缩小，避免只依赖颜色反馈。
- 对话页导航在桌面端显示名称和用途，在手机端只保留带提示文字的图标按钮。
- 系统开启“减少动态效果”时，不播放遮罩转场、鼠标跟随和涟漪，直接完成页面跳转。

## 比赛评分对应

- 创新性：将游戏化活动转场转化为心理健康产品的空间连续体验。
- 需求与体验：通过明确的目标标题和操作反馈降低用户对页面跳转的不确定感。
- 项目实施：共用 `page-transition.css` 与 `page-transition.js`，三页面保持一致并便于维护。
- 应用成效：后续可在可用性测试中记录入口识别率、误触率、跳转完成率与主观舒适度，当前不得表述为已验证成效。

## 首页背景动态（2026-09-17）

沿用用户提供的 `landing-room.jpg`，通过原创 CSS/JavaScript 增加窗内细雨、20 秒一周期的轻微缩放和鼠标景深跟随。文字、导航和按钮不随背景位移，雨滴根据原图尺寸及背景裁切比例定位，避免落在窗框和室内区域。

- 桌面鼠标位移上限为横向 8px、纵向 5px；触屏设备不启用鼠标跟随。
- 右下角图标按钮关闭或开启背景动态，选择仅保存在当前浏览器，不采集个人数据。
- 系统“减少动态效果”优先，自动关闭背景动态；页面隐藏或背景离开视口时暂停动画。
- 无新增外部依赖，继续使用已有 Lucide 图标和原图素材，来源见现有素材说明。
- 对应项目实施评分：保留实现说明、响应式截图及验证记录。舒适度改善属于设计目标，尚未通过用户研究验证。

验收：桌面及 390px、820px、1920px 布局无横向溢出；背景缓慢运动、鼠标跟随、手动关闭与偏好记忆、系统减少动态效果、离屏暂停和触屏开关均正常；首页导航及随笔流程通过原有浏览器回归检查。截图与检查结果保存在本地 `output/landing-journal/landing-motion-*.png` 和 `motion-verification.json`。

## 转场与纸飞机音效（2026-09-17）

- 页面转场：点击有效的站内跳转入口时播放 0.28 秒、最高频率低于 2kHz 的柔化空气声，淡入 50ms、淡出 150ms；不包含提示音或明确音高，到达页面不重复播放。
- 心灵随笔：完成按钮触发三次 90–110ms 的低通绒布摩擦声，1.25 秒起同步飞机动画播放由近及远、轻微向右移动的低频风声，末段以 720ms 缓慢淡出；不包含清脆纸张声和提示音。
- 所有音效由共享的 `sound-effects.js` 在浏览器内合成，不上传随笔内容，无额外音频下载、接口或费用。各页面有独立于 AI 朗读的界面音效开关，默认开启，静音偏好仅保存在浏览器。
- 手动静音、页面离开或切到后台时停止播放；系统开启减少动态效果时不播放这些动画配音。浏览器不支持或限制音频时，导航和随笔完成流程仍可正常使用。
- 对应项目实施评分：以同步节奏、可控音量、状态恢复和兼容性验证作为交付标准；舒适度与情绪改善不作为已验证结论。

验证记录：`output/sound-effects/` 保存浏览器播放检查、波形非静音及无削波数值、320/390/1440px 页面截图和本地纸飞机试听文件。音效的主观听感仍可结合真实试用反馈调整。
