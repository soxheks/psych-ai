# 公开体验稳定性与心理安全记录

## 目标

本轮改动对应比赛的 AI 技术应用、项目实施、应用成效和心理安全要求，目标是让公开演示在多人使用、异常输入和危机表达下仍有可预期的行为。

## 运行保护

- 单条用户输入在浏览器和服务端都限制为 4000 字。
- 浏览器当前标签页使用随机匿名 ID 做每分钟 12 次限流，不包含用户内容。
- 额外设置每分钟 120 次的网络级保护，防止绕过浏览器 ID 直接滞用公开接口。
- 同一匿名 ID 同时只允许一条 AI 回复；锁在流结束、异常或 55 秒超时后释放。
- Render 使用 1 个 `gthread` worker 和 8 个线程，使阻塞式豆包请求不至于完全堵住其他访客。
- 生产环境强制 HTTPS，Session 和 CSRF Cookie 仅通过 HTTPS 发送，并恢复被 SimpleUI 移除的同源防点击劫持保护。

## 心理安全

- 保留明确自伤、自杀和伤人词表，新增“不想再醒来”“永远睡过去”“撑不下去”“一了百了”等委婉表达。
- 对只包含明确否定的短句，例如“我没有想过自杀”，避免误入危机流程。
- 危机状态继续清空普通对话记忆、停止语音和角色娱乐动作，并引导联系可信任的人、学校心理中心和紧急支持。
- 当前仍是规则式高风险拦截，不等同于临床风险评估；后续需继续使用人工审核的句子集测试漏报与误报。

## 可解释与数据口径

- 用户可在“数据、进度与对话要点”中查看、修改或清除 AI 提取的主要困扰与已确认要点。
- 要点默认仅保留在当前页面；只有用户主动开启本地进度时才会保存在本设备。
- 匿名效果数据的撤回范围明确为“当前浏览器会话内”。
- 完整前后评分少于 10 份时，首页只展示事实计数，不展示平均变化或趋势结论。这个阈值可通过 `OUTCOME_MINIMUM_SAMPLE` 调整。
- 不创建、补齐或推测任何真实试用数据。

## 性能

- 角色图集从 1381.5KB PNG 转为 164.2KB WebP，页面实际加载体积减少约 88%。
- 首页动态数据的公开缓存由 1 小时缩短为 60 秒，避免用户同意贡献后长时间看不到更新。

## 验证方式

- Django 测试覆盖：输入上限、限流、流式并发锁、委婉危机表达、明确否定句、样本展示阈值。
- 浏览器测试覆盖：320/390/1280/1440px 布局、流式文字、可编辑对话要点、安全分流、语音、动作卡、随笔和页面转场。
